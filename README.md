Aplicación de lista de tareas desarrollada en **Kotlin** para Android 📱.  
Proyecto de la asignatura **DESARROLLO DE SOFTWARE PARA MÓVILES DSM441 **.

---

## 🧠 Descripción

TO DO LIST permite a los usuarios crear tareas personalizadas y marcarlas como completadas.  
Al marcar una tarea, desaparece del listado automáticamente, ayudando a mantener el enfoque y la productividad.

---

## ✨ Características

- Añadir nuevas tareas de forma sencilla  
- Marcar tareas como completadas con un toque  
- Eliminación automática al marcar ✅  
- Diseño intuitivo y moderno

---

## 🚀 Tecnologías utilizadas

- Kotlin  
- Android SDK  
- Android Studio
